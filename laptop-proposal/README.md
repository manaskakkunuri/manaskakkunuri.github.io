# Laptop Proposal — Browser Presentation

This presentation lives at \`laptop-proposal/index.html\` inside the existing \`manaskakkunuri.github.io\` repository. It is deliberately kept separate from the existing Ultron home page.

## What it includes
- 15 detailed slides on study goals, HP OmniBook 3 and ASUS Vivobook 16, RAM and SSD storage, CPU/GPU/NPU, 45 TOPS, software engineering, Ultron, Windows ARM compatibility, a 30-day learning plan, budget and final checklist.
- Product image links and buttons for Google Images, Amazon India, and official product references.
- Slide navigation, keyboard arrows, view-all mode, print/save as PDF, and copy-link button.
- Optional Gemini closing video. Upload a compressed MP4 to \`laptop-proposal/assets/gemini_closing.mp4\`.
- No external JavaScript libraries or build step is required.

## Accuracy notes
- HP ₹50,000–₹55,000 is a target discussed for the purchase, not a verified live checkout offer.
- The HP picture is from a related OmniBook 3 configuration, not verified as the exact Indian SKU. Treat it as illustrative; use the model and product links to confirm the actual offered machine.
- Check warranty, seller, exact SKU, port/battery specs, final checkout price and all financing costs before purchasing.
- Google's Android Studio documentation says Windows computers with ARM-based CPUs are not currently supported. Test the full development workflow before buying.
- Product images are hotlinked from third-party sites and may fail to display if the host blocks them. The image-search and product-page links are available as alternatives.
- If adding a Gemini video, keep it reasonably compressed. Large videos make repositories heavy.
